# What you assert

A claim about how a tool, platform or library behaves is checked against its current docs, a run or the installed version before you write it down anywhere, with the link or command beside it. A search that finds nothing is not the docs. The types, the repo's own prose and a remembered API are not the platform either: they are where a wrong claim reads as checked.

A claim about this repository — what a file holds, which change touched it, what its rules say — is read from the repo first, with the file or command beside it.
